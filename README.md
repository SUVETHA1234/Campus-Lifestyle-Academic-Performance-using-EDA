# Campus Lifestyle and Academic Performance Analysis Using Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on student lifestyle and academic performance data to identify patterns, relationships, and key influencing factors affecting exam scores.

The project uses Python-based data analysis libraries to preprocess, analyze, visualize, and interpret the dataset.

The study investigates the impact of:
- Study Hours
- Sleep Duration
- Social Media Usage
- Attendance Percentage
- Extracurricular Activities

on student academic performance.

---

# Objectives

The primary objectives of this project are:

1. To analyze academic performance data using Exploratory Data Analysis.
2. To identify correlations between lifestyle factors and exam scores.
3. To visualize trends and distributions within the dataset.
4. To generate meaningful insights from the data.
5. To improve analytical thinking and data interpretation skills.

# Key Findings

- Increased study hours positively influence exam scores.
- Higher attendance percentage strongly correlates with better academic performance.
- Excessive social media usage negatively impacts exam results.
- Balanced sleep improves concentration and performance.
- Students involved in extracurricular activities show slightly improved performance.

# Conclusion

This project demonstrates how Exploratory Data Analysis can be used to extract meaningful insights from educational datasets.

The analysis highlights the importance of balanced lifestyle habits and consistent academic engagement for improved student performance.
